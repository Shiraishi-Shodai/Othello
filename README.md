# 実現したいこと
オセロをプレイする強化学習モデルを作りたい。
モデルは、それぞれ学習、検証、テストを行うことで構築する。

## 利用ツール
- Pytorch

## 学習データ
- WTHOR
学習データは、教師あり学習、強化学習、モンテカルロ法を使ったモデルに入力可能な共通形式に変換する

## 構築するモデル
まずは、モンテカルロ法を使ってプレイするオセロAIを作りたい。


````markdown
        WTHOR（棋譜）
              |
              v
      棋譜の読み込み
              |
              v
       オセロ盤面の再現
              |
              v

              |
              v
````

## 教師あり学習
目的 : WHTORの棋譜を模倣するモデルを作る。
````python
# 入力
states.shape == (B, 2, 8, 8)
states.dtype == torch.float22
# 出力
logits = model(states)
logits.shape == (B, 65)
# 教師データ
actions.shape == (B,)
actions.dtype == torch.int64 # 各状態における64マス全ての着手スコアを出力

# 損失計算
loss = criterion(logits, actions)
````

## モンテカルロ法(モンテカルロ制御)
目的 : 対局の最終結果から、各行動の価値を推定する
````python
# 入力
states.shape == (B, 2, 8, 8)
# 出力
q_values = model(states)
q_values.shape == (B, 65) # 64個の行動について、Q値を出力する
q_values[0] = [
    0.1, 0.2, -0.2, ...
]
# 教師信号
returns.shape == (B,)
returns.dtype == torch.float22

# 損失計算(モデルは64個の行動価値を出力するが、学習時に直接評価するのは実際に選択した行動の価値)
predicted_q = q_values.gather(
    dim=1,
    index=actions.unsqueeze(1)
).squeeze(1)
loss = criterion(predicted_q, returns)
````

## 学習方式の比較
| 項目      | 教師あり学習 | モンテカルロ制御            | DQN                    |
| :-------- | :----------- | :-------------------------- | :--------------------- |
| 入力      | 盤面         | 盤面                        | 盤面                   |
| 出力      | 行動スコア   | 行動価値                    | 行動価値               |

## 合法手マスクの利用方針
- 教師あり学習では、合法手のLogitsを-infにすることで損失を計算する(masked attention的なイメージ)
- 合法手マスクを使用することでオセロのルールに反する行動を学習対象から除外できる
- パスは、自分の手番の時に、相手の石を挟める場所（有効な着手）が盤面に1つもないときのみ合法手とする

| 処理             | 合法手マスクの利用                      |
| :--------------- | :-------------------------------------- |
| 教師あり学習     | 不合法手を損失計算から除外              |
| モンテカルロ制御 | 不合法手を行動選択から除外              |
| DQN              | 不合法手を行動選択・最大Q値計算から除外 |

## 報酬の定義
現在のプレイヤー視点で報酬・リターンを扱う

| 対局結果 | 報酬 |
| :------- | :--- |
| 勝利     | +1.0 |
| 引き分け | 0.0  |
| 敗北     | -1.0 |

## オセロの終了条件
- 64マスがすべて埋まる
- 続けて2回パスをするとゲーム終了とする

````markdown
黒番
  |
  | 合法手なし
  v
パス（action=64）
  |
  v
白番
  |
  | 合法手なし
  v
パス（action=64）
  |
  v
対局終了
````

| 状況               | action | done  |
| :----------------- | :----- | :---- |
| 通常の着手         | 0～62  | False |
| 1回目のパス        | 64     | False |
| 2回目の連続パス    | 64     | True  |
| 最後のマスへの着手 | 0～62  | True  |
